# Вага — інсталятори

Тут лише готові інсталятори програми «Вага» для ноутбука біля автомобільної ваги (Windows 10/11, 64-біт).
Код програми тут не зберігається.

- **Встановлення або оновлення вручну:** завантажте `Vaga-Setup-X.Y.Z.exe` з [останнього релізу](../../releases/latest)
  і запустіть від імені адміністратора. Дані (база, копії) у `C:\ProgramData\Vaga` не чіпаються.
- **Автоматично:** програма сама перевіряє цю сторінку, коли є інтернет, і пропонує оновлення
  в «Налаштування → Оновлення програми».
- Поруч з кожним інсталятором лежить `.sha256` — програма звіряє його перед встановленням.
